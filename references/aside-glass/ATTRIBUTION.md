# 출처와 자산

이 항목은 Aside UI의 독립적인 디자인 연구다. Aside의 공식 배포물이나 제휴 프로젝트가 아니다. 앱 바이너리, 원본 번들 이미지, 로그인 상태 또는 사용자 대화 기록을 배포하지 않는다. 화면 내용은 합성 예시다.

- 원본 제품: [Aside](https://aside.com), 분석 버전 1.0.928.1. CSS/JavaScript 선언에서 얻은 값과 관찰을 근거로 재구현했다. 원본 코드 전체는 포함하지 않는다.
- 글꼴: [Geist](https://github.com/vercel/geist-font), The Geist Project Authors, SIL Open Font License 1.1. 수정하지 않은 variable WOFF2와 [라이선스](assets/OFL.txt)를 함께 배포한다.
- 공개용 배경: Patrick Fore의 [Photography of pine trees covered with fogs](https://unsplash.com/photos/photography-of-pine-trees-covered-with-fogs-vpAKO21abME). [Unsplash License](https://unsplash.com/license)로 제공되는 사진을 UI 시연 배경으로 사용한다. 원본 Aside 번들의 Forest 자산과 다르다.
- 프로토타입과 설정 화면: 이 디자인 연구를 위해 작성한 HTML/CSS/JavaScript다. 설정 화면과 B/C의 정보 구조는 새 제안이다.

원본 디자인 분석, 재사용 구현, 배포 자산의 출처를 각각 구분해 기록한다. 원본 앱의 네이티브 픽셀 일치나 동작 일치가 검증됐다는 의미는 아니다.
