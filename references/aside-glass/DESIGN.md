# Aside / Glass workspace

Aside 1.0.928.1의 새 대화와 사이드바 관련 CSS/JavaScript 선언에서 추출한 디자인 연구다. 웹에서 다시 만든 기준안과 구조 변형, 같은 문법으로 만든 새 설정 화면을 포함한다. 실제 서비스 연결과 네이티브 창 프레임은 구현 범위에 포함하지 않는다.

## 읽는 순서

1. `index.html`: 원본 구조 기준안 A, 프로젝트 중심 B, 대화와 자료 분할 C.
2. `settings.html`: 추출 당시 없던 새 화면에 규칙을 적용한 예시.
3. `tokens.json`: 타입과 의미를 갖춘 값, 테마, 별칭. 미리보기의 CSS는 이 파일에서 생성한다.
4. `evidence/extraction.json`, `reference.json`: 원본 근거, 구현 차이와 검증 범위.

## 디자인 원칙

작업 내용이 중심이고 조작부는 낮은 대비와 짧은 높이로 정돈한다. 글꼴과 간격, 가는 경계선으로 위계를 만든다. 투명 표면은 배경이 있는 경우에만 재질을 보여주며 읽기 대비를 먼저 유지한다. 같은 표면에 여러 강한 그림자나 장식색을 추가하지 않는다.

## 토큰과 타이포그래피

원본의 83개 선언을 분석 자료에 보존했다. 테마의 같은 속성에 대한 fallback 선언은 최종 선언으로 합치고, 참조 색상과 재현용 치수를 보충해 90개 타입 토큰으로 정리했다. `base`는 글꼴/크기/간격/공통 색, `light`와 `dark`는 역할별 표면과 콘텐츠 색이다.

본문은 `base.font-sans`를 사용한다. 공개본에는 Geist Variable의 OFL 배포본을 포함한다. `base.font-mono`의 서체 목록은 원본 선언 기록이며 상업용 폰트 파일을 포함한다는 뜻이 아니다. 원본의 없는 글꼴은 fallback으로 처리한다.

`base.spacing`은 간격 단위다. `base.radius-*`는 원본의 squircle factor를 반영한 유효 반경이다. 문서와 미리보기에 별도 값 사본을 유지하지 않고 토큰 값을 수정한 뒤 다시 빌드한다. 도구 모음의 검수 UI는 제품 디자인 시스템의 일부가 아니다.

## 레이아웃과 밀도

A는 왼쪽 작업 탐색과 넓은 대화 영역, 하단 입력 영역으로 구성한다. B는 프로젝트 자료를 먼저 보여주며 C는 대화 목록과 참고 자료를 분리한다. B/C의 정보 구조와 내용은 새 제안이다.

사이드바는 `base.sidebar-width`, 기본 텍스트는 `base.text-sm`, 가는 경계선은 `light.hairline`을 사용한다. 좁은 화면에서는 사이드바를 숨겨 대화 입력 영역을 우선한다. 패널을 숨겨도 현재 입력과 선택 상태를 보존한다. 모바일 메뉴가 열릴 때 본문 포커스를 차단하고 닫을 때 호출 버튼으로 돌린다.

## 컴포넌트와 상태

- 탐색 행: 짧은 높이, 작은 모서리, 낮은 대비의 선택 표면. 선택 상태와 hover를 구분한다.
- 입력 영역: 입력 내용, 첨부 자료, 전송, 권한/프로젝트/모델 메뉴를 한 작업 단위로 구성한다. 빈 입력의 전송은 비활성이다.
- 작업 상태: 빈 상태, 진행 중, 오류, 예시 대화를 같은 화면 구조 안에서 전환한다. 오류에서도 입력을 보존한다.
- 설정 화면: 같은 토큰으로 표면, 행, 선택 입력과 저장 영역을 구성한다. 토글과 설정 그룹, 저장 성공/오류 흐름은 새 제안이다.

## 표면과 글래스 합성

공통 글래스의 근거는 `evidence/extraction.json`의 `glass.common_glass`에 있다. 표면 혼합 비율, `base.glass-blur`, 안쪽 테두리와 바깥 윤곽을 각각 사용한다. 뒤에 실제 배경이 있고 중간 불투명 패널이 합성을 막지 않아야 한다.

Liquid 변형은 번들의 실험용 레이어를 기준으로 재구성한 것이다. 일반 글래스와 같은 원본 기본 스타일이라고 간주하지 않는다. 반사, 명암, 가장자리 레이어의 순서와 blend mode를 함께 보존한다. 실제 네이티브 운영체제 재질을 복제했다는 뜻도 아니다.

공개본에서는 대체 사진의 밝은 영역 위에서도 어두운 테마의 글자를 읽을 수 있도록 `dark.liquid-base` 틴트를 제안해 추가했다. 이 값은 원본 추출 토큰이 아니다.

공개본의 숲 사진은 원본 번들 이미지의 대체 자산이다. 재질과 배경의 상호작용을 확인하는 용도이며 원본 화면의 픽셀 일치 근거로 사용하지 않는다. 단색 모드에서는 투명 효과를 끄고 불투명 표면을 사용한다.

## 접근성과 모션

텍스트와 입력 요소의 레이블을 유지한다. 포커스 윤곽을 색상과 굵기로 구분하고 아이콘 버튼에는 접근 가능한 이름을 둔다. 입력 중 한글 조합 Enter를 전송으로 처리하지 않는다. OS의 움직임 축소 설정을 존중하며 설정 예시에도 별도 모션 축소 선택을 제공한다.

밝은/어두운 테마와 좁은/넓은 화면을 각각 검사한다. 실기기 네이티브 접근성이나 모든 색 조합의 대비 인증은 이 연구의 검증 범위에 포함하지 않는다.

## 검증과 적용 범위

실제 실행 결과는 `evidence/verification.md`와 `reference.json`에 기록한다. 네이티브 앱과의 픽셀 동일성은 미검증이다. 다른 서비스에 적용할 때는 대상 플랫폼과 기존 스택을 먼저 확인하고, 의미 토큰과 컴포넌트 문법을 옮긴 뒤 대표 화면으로 다시 비교한다.
