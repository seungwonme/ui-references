A little more context.

What is this reference testing?

Typography hierarchy, restrained controls, generous section rhythm and a product-led story. The values are measured from a selected Apple page; this layout and product are new.

Does this include Apple’s product artwork?

No. The preview uses original HTML and CSS artwork, system fonts and fictional copy.

Folio is a fictional product used to test this design system. All interface artwork is authored for this study.

Source: Apple MacBook Pro web page, observed October 19, 2026. No Apple images, logos, marketing copy or font files are redistributed.
